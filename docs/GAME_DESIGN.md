# Splash Bash! 물총 대소동 — 게임 설계

귀엽고 둥근 콩 캐릭터들이 뒷마당 수영장 파티에서 물총 싸움을 벌이는 **브라우저 3D 1인칭 캐주얼 슈터**.
설치 없이 링크 하나로 바로 들어가 **서버 없이(P2P)** 친구와 대전한다.

근거 자료: `docs/research/` (리서치 4편 + 종합안). 각 결정 옆 `[ ]` 는 참고한 실제 게임.
수치의 단일 출처는 `src/config.ts` 이다. 이 문서와 다르면 코드가 맞고 문서를 고친다.

## 1. 핵심 루프

적 발견 → 물줄기로 적심(약 0.6초) → 탱크 바닥 → 분수·수영장에서 보충(노출 위험) 또는 물러나 말리기 → 재교전.
흠뻑 젖으면(soak 100) 3초 뒤 부활. 한 경기 4분, 결과 화면 8초 후 같은 방에서 다음 경기. [스플래툰 쏘기/보충 리듬, Krunker·Smash Karts 짧은 라운드]

## 2. 접속 흐름 (1~2클릭)

- 첫 화면: 자동 생성 닉네임(예: "촉촉한수달"), 색·모자 꾸미기, **빠른 대전** 큰 버튼, 방 만들기/코드 참가, 연습 모드. 계정 없음. [Krunker 게스트, Shell Shockers]
- 빠른 대전: 공개 방 `quick-1`에 참가 → 사람이 8명 이상이면 다음 방으로. 혼자여도 즉시 시작하고 봇이 채운다(대기 없음).
- 초대: URL `#room=코드` 가 곧 초대장. Esc 메뉴에서 "초대 링크 복사". [Smash Karts]
- 연습 모드: 네트워크 없이 봇과 대전.

## 5. 젖음(체력)

- soak 0~100, 100이 되면 **흠뻑 젖었다!** (쓰러짐)
- 마지막으로 맞고 1.5초 뒤부터 초당 15씩 마른다. [스플래툰 1초, 12.5/s]
- 헤드샷·치명타 없음. 젖어도 느려지지 않음(패배 악순환 방지).
- 시각: 젖을수록 몸이 파래지고, 화면 가장자리 물방울이 늘어난다.

## 6. 물탱크

- 100. 발사를 멈추고 0.6초 뒤부터 초당 8 회복(빈 탱크 → 가득 12.5초). [스플래툰 서 있을 때 10초]
- **분수**(반경 1.5 m): 초당 30. **수영장**: 초당 60, 대신 이동 ×0.7 — 맵 한가운데서 노출되는 위험·보상 구역. [스플래툰 잠수 충전]
- 물이 모자라면 헛발사(딸깍), 20 이하에서 "물 부족!" 경고.
- 물풍선도 탱크 물 40을 쓴다(자원 하나로 단순화). [스플래툰 서브웨펀]

## 7. 무기 (총 3 + 물풍선)

모든 물줄기는 **일정 시간 곧게 날다가 공기저항·중력으로 처진다** — 물줄기가 처지는 지점이 곧 사거리라서 눈으로 사거리를 배운다. [스플래툰]
물방울 판정 반지름: 플레이어 대상 0.15 m(너그럽게), 벽 대상은 물방울 중심.

| | 퐁퐁 권총 (정밀) | 슈퍼 소커 (연사) | 양동이 블래스터 (근접 산탄) | 물풍선 (투척) |
|---|---|---|---|---|
| 참고 | 스플래툰 .52 Gal / Krunker 권총 | 스플래슈터 / Krunker AR | 스플래툰 슬로셔 / Krunker 샷건 | 스플래툰 버스트밤 |
| 발사 | 반자동 0.22초 | 자동 초당 10발 | 0.7초마다 10방울 | 쿨다운 1.2초 |
| 속도 | 60 m/s, 직진 0.3초 | 40 m/s, 직진 0.25초 | 22 m/s, 직진 0.1초 | 14 m/s + 위 2.5 |
| 적심 | 25 (거리 따라 15까지 감소) | 16 → 8 | 방울당 10 → 4 | 직격 60, 폭발 45 → 15 (반경 3 m) |
| 물 소모 | 4 | 1.5 | 8 | 40 |
| 적시기까지 | 4발 ≈ 0.66초 | 7발 ≈ 0.6초 | 근접 1~2방 | 콤보용 |

무기는 1/2/3 또는 휠로 언제든 바꿀 수 있다(교체 0.25초). 종합안의 "목숨당 무기 1개" 대신 캐주얼 친화성을 택했다.

## 8. 맵: 뒷마당 수영장 파티

- 플레이 영역 48 × 36 m, 동서 3개 레인(z = +13, 0, −13), 180° 회전 대칭(팀전 공정성).
- 높이: 수영장 바닥 −0.65 / 지면 0 / 파티오 +1.0(점프로 오름) / 전망대 +3.6.
- 중앙 강낭콩 모양 수영장(14 × 7 m, 충전 구역), 양 끝 파티오(팀 진영), 카바나 2, 티키 바 2, 산울타리 4, 트리하우스·놀이터 전망대 2(각각 계단·점프대·경사로 3가지 길), 분수 2, 빨랫줄 2.
- 시야선 대부분 10~20 m, 최대 35 m. 스폰 12곳(팀전은 자기 파티오 4곳).
- 상세: `docs/research/design-synthesis.md` §10, 에셋 규약: `docs/ASSETS.md`.

## 9. 아트

- 콩 캐릭터(머리·몸 일체, 큰 눈, 벙어리장갑 손, 작은 발), 모든 형태에 베벨·서브디비전 — 날카로운 모서리 금지. [Fall Guys]
- 캐릭터가 화면에서 가장 채도가 높고 배경은 30% 이상 채도를 낮춘다.
- 파란색은 팀 색으로 쓰지 않는다(물·하늘과 겹침). 팀: 탠저린 `#FF8A1F` / 그레이프 `#7B5CFF`. [스플래툰 3 팀색 가독성 문제]
- 물줄기는 쏜 사람 색 35% + 물빛 `#BFF3FF` — 누가 쏘는지 보인다.
- 툰 셰이딩 3단 램프 + 역방향 헐 외곽선 + 림 라이트, NeutralToneMapping.
- UI: Jua 폰트, 알약 모양 버튼, 흰 글자 + 진한 테두리. 폭력적 단어 금지("죽음" 대신 "흠뻑 젖었다!").

## 10. 넷코드 (서버리스)

- **Trystero** + 공개 Nostr 릴레이로 WebRTC 시그널링만 하고, 게임 데이터는 브라우저끼리 직접(P2P 풀 메시) 주고받는다. 운영 서버·DB 없음.
- 권한 모델:
  - 각 플레이어: 자기 이동·탱크·젖음·쓰러짐.
  - 쏜 사람: 명중 판정(자기가 보는 화면 기준, "쏜 사람 우선"). [스플래툰, Halo: Reach]
  - 호스트(가장 먼저 들어온 사람): 경기 시간·점수·팀 배정·봇. 나가면 다음 사람이 이어받는다.
- 전송: 상태 20 Hz(JSON 배열), 발사·명중·쓰러짐·경기 상태는 이벤트로. 원격 캐릭터는 110 ms 과거를 보간.
- 모든 수신 데이터는 검증(형식·범위·보낸 사람 권한). 발신자 id 는 전송 계층이 보증한 값만 신뢰.
- 한계(문서화): 대칭형 NAT 끼리는 TURN 없이 연결이 안 될 수 있다(`VITE_TURN_*` 로 TURN 설정 가능). 치트하는 호스트·클라이언트를 서버 없이 완전히 막을 수는 없다(캐주얼 게임으로 수용).

## 11. 봇

호스트에서만 실행, 사람과 같은 물리·무기 코드. 웨이포인트 그래프(A*) 이동, 시야 110°/30 m, 반응 지연 0.4~0.7초, 조준 오차(가우시안 4° → 2°), 탱크 부족 시 보충하러 감, 교전 중 좌우 무빙·점프. 이름·모자는 귀엽게, 점수판에 "봇" 표시.
